## 🧪 测试步骤

### 1. 生成知识图谱
1. 打开浏览器访问 `http://localhost:3000`
2. 输入一个概念（如："量子纠缠"）
3. 点击"生成知识图谱"
4. 等待图谱生成完成

### 2. 测试导出功能

#### 测试 JSON 导出
1. 点击"📥 导出图谱"按钮
2. 选择"📄 导出为 JSON"
3. 检查下载的 JSON 文件
4. 验证包含：concept、graph_id、nodes、edges、exported_at

#### 测试 PNG 导出
1. 点击"📥 导出图谱"按钮
2. 选择"🖼️ 导出为 PNG"
3. 检查下载的 PNG 图片
4. 验证图谱清晰度和完整性

#### 测试 Markdown 导出
1. 点击"📥 导出图谱"按钮
2. 选择"📝 导出为 Markdown"
3. 检查下载的 Markdown 文件
4. 验证包含：
   - 核心概念信息
   - 图谱统计
   - 学科领域分类
   - 跨学科关联关系详情

## 📁 导出文件示例

### JSON 格式
```json
{
  "concept": "量子纠缠",
  "graph_id": "abc123...",
  "graph": {
    "nodes": [...],
    "edges": [...]
  },
  "exported_at": "2026-01-19T13:30:00.000Z"
}
```

### Markdown 格式
```markdown
# 跨学科知识图谱报告

## 核心概念：量子纠缠

---

## 📊 图谱统计
- **节点总数**：10
- **关系总数**：9
- **涉及学科**：5
...
```
