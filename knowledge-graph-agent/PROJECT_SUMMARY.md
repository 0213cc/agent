## 🔧 技术架构

### 后端
- **框架**: FastAPI
- **数据库**: Neo4j（图数据库）
- **缓存**: Redis
- **LLM**: DeepSeek-V3
- **API**: 维基百科 API + Semantic Scholar API

- **2D 可视化**: ECharts
- **3D 可视化**: 3d-force-graph + Three.js

## 🐛 已知问题和解决方案

### 1. Semantic Scholar API 429 错误
**问题**: 短时间内请求过多导致速率限制  
**解决**: 添加 Redis 缓存（24 小时），大幅减少 API 请求

### 2. 维基百科 403 Forbidden
**问题**: Docker 容器请求被维基百科阻止  
**解决**: 添加 User-Agent 和 Accept 请求头

### 3. 右键点击重复触发
**问题**: 一次点击发送多次请求  
**解决**: 添加防抖机制（300ms + 50ms 延迟 + useCallback）

### 4. 3D 视图节点文字模糊
**问题**: Canvas 渲染的文字精灵分辨率不足  
**解决**: 增大 Canvas 尺寸到 512x512，优化文字渲染
