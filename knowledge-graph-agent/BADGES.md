## 使用说明

1. 将 `YOUR_USERNAME` 替换为你的 GitHub 用户名
2. 将 `YOUR_REPO` 替换为你的仓库名
3. 复制到 README.md 文件中

## 徽章样式

可以添加 `?style=` 参数来改变样式：
- `flat` - 扁平样式（默认）
- `flat-square` - 扁平方形
- `for-the-badge` - 大徽章
- `plastic` - 塑料样式
- `social` - 社交样式

示例：
```markdown
![CI/CD](https://github.com/YOUR_USERNAME/YOUR_REPO/workflows/CI/CD%20Pipeline/badge.svg?style=for-the-badge)
```
