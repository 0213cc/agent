# 跨学科知识图谱智能体 - 功能总结

## 🎯 项目概述

基于云原生架构的跨学科知识图谱智能体，利用 LLM 挖掘不同学科间的深层关联，并提供可视化展示和智能分析功能。

---

## ✅ 已完成功能（4/6）

### 功能 1: 图谱导出 📥
**实现时间**: 2026-01-19

**核心能力**:
- 导出为 JSON（完整数据结构）
- 导出为 PNG（高清图谱截图）
- 导出为 Markdown（详细分析报告）

**云原生特征**:
- RESTful API 设计
- 前后端分离架构
- 标准化数据格式

**技术栈**:
- 后端: FastAPI + Python
- 前端: React + html2canvas
- 格式: JSON, PNG, Markdown

---

### 功能 2: 智能摘要生成 ✨
**实现时间**: 2026-01-20

**核心能力**:
- 自动分析图谱结构（节点数、边数、学科分布）
- 识别关键概念和核心关系
- 使用 LLM 生成自然语言摘要（200字）
- 提取跨学科洞察

**云原生特征**:
- LLM 服务集成（DeepSeek-V3）
- 异步处理
- 智能分析服务

**技术栈**:
- LLM: DeepSeek-V3
- 后端: FastAPI + LLMClient
- 前端: React 状态管理

**示例输出**:
```
熵是物理学中描述系统无序程度的核心概念，在信息论、统计力学、
热力学等多个学科中都有重要应用。本图谱展示了熵与信息论、统计
力学、热力学第二定律等概念的深层联系...
```

---

### 功能 3: 维基百科集成 📖
**实现时间**: 2026-01-20

**核心能力**:
- 为每个节点查询维基百科
- 显示标题、描述、摘要、缩略图
- 提供跳转链接
- 右键点击节点查看详情

**云原生特征**:
- 外部 API 集成（维基百科 REST API）
- 前端直接调用（绕过 Docker 网络限制）
- 容错处理（无结果时友好提示）

**技术栈**:
- API: Wikipedia REST API v1
- 前端: Fetch API + React
- 交互: 右键菜单

**API 端点**:
```
https://zh.wikipedia.org/api/rest_v1/page/summary/{concept}
```

### 功能 4: 文献推荐 📚
**实现时间**: 2026-01-20

**核心能力**:
- 推荐学术论文（Semantic Scholar）
- 显示论文标题、作者、年份、摘要、引用次数
- 提供论文链接
- 在节点详情面板中展示

**云原生特征**:
- 外部学术 API 集成
- 异步 HTTP 请求（aiohttp）
- 微服务架构（独立端点）
- RESTful API 设计

**技术栈**:
- API: Semantic Scholar Graph API
- 后端: FastAPI + aiohttp
- 前端: React + Axios

**API 端点**:
```
https://api.semanticscholar.org/graph/v1/paper/search
```

**数据示例**:
```json
{
  "title": "Deep Learning",
  "authors": ["Ian Goodfellow", "Yoshua Bengio", "Aaron Courville"],
  "year": 2016,
  "citations": 45000,
  "abstract": "...",
  "url": "https://..."
}
```

## 🌐 云原生特征总结

### 架构设计
```
┌─────────────────────────────────────────┐
│           用户浏览器 (React)             │
│  - 图谱可视化                            │
│  - 智能摘要展示                          │
│  - 维基百科/文献推荐                     │
└─────────────┬───────────────────────────┘
              │ HTTP/REST
┌─────────────▼───────────────────────────┐
│      后端 API (FastAPI)                  │
│  - /api/graph/generate                   │
│  - /api/graph/summary                    │
│  - /api/literature/{concept}             │
│  - /api/graph/export/markdown            │
└─────┬───────┬───────┬────────────────────┘
      │       │       │
      │       │       └─────────────┐
      │       │                     │
┌─────▼───┐ ┌─▼──────┐ ┌──────────▼────────┐
│ Neo4j   │ │ Redis  │ │ 外部 API          │
│ 图数据库 │ │ 缓存   │ │ - Wikipedia       │
│         │ │        │ │ - Semantic Scholar│
└─────────┘ └────────┘ └───────────────────┘
```

### 云原生组件
1. **容器化** - Docker + Docker Compose
2. **微服务** - 前端、后端、数据库、缓存分离
3. **API 网关** - Nginx 反向代理
4. **缓存层** - Redis 缓存图谱数据
5. **图数据库** - Neo4j 存储知识图谱
6. **外部集成** - Wikipedia、Semantic Scholar
7. **异步处理** - aiohttp 非阻塞请求
8. **容错机制** - 网络失败优雅降级

### Kubernetes 支持
- 已准备 K8s 配置文件（`k8s/` 目录）
- 支持多实例部署
- 支持服务发现和负载均衡

## 📈 性能指标

### 响应时间
- 图谱生成: 30-60 秒（取决于概念复杂度）
- 智能摘要: 3-5 秒
- 维基百科查询: 1-2 秒
- 文献推荐: 2-3 秒
- 节点扩展: 20-40 秒

### 缓存效果
- 缓存命中: 返回时间 < 100ms
- 缓存 TTL: 3600 秒（1小时）
- 缓存存储: Redis

### 数据规模
- 初始节点数: 10-15 个
- 初始关系数: 9-14 个
- 涉及学科: 5-8 个
- 扩展后节点: 可达 50+ 个
