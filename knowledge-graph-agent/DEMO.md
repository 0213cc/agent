# 🎬 功能演示指南

## 🚀 快速开始

### 1. 访问应用
打开浏览器访问: **http://localhost:3000**

---

## 📋 演示流程

### 第一步：生成知识图谱
1. 在输入框中输入概念，例如：**"熵"**
2. 点击"生成知识图谱"按钮
3. 等待 30-60 秒，观察生成过程

**预期结果**:
- ✅ 显示加载动画和提示文字
- ✅ 生成包含 10+ 个节点的跨学科知识图谱
- ✅ 涉及物理学、信息论、统计学等多个学科

---

### 第二步：查看智能摘要 ✨
图谱生成后，自动显示智能摘要卡片

**观察内容**:
- 📝 200字左右的自然语言摘要
- 🔑 关键概念及其连接数
- 📊 图谱统计信息（节点数、关系数、学科数）

**示例摘要**:
```
熵是物理学中描述系统无序程度的核心概念，在信息论、统计力学、
热力学等多个学科中都有重要应用。本图谱展示了熵与信息论中的
香农熵、统计力学中的玻尔兹曼熵、热力学第二定律等概念的深层
联系，揭示了跨学科知识的内在统一性...
```

---

### 第三步：扩展节点 🔍
**左键单击**任意节点（如"信息论"）

**预期结果**:
- ✅ 节点周围生成新的关联概念
- ✅ 图谱动态更新
- ✅ 摘要自动重新生成

**提示**: 可以多次扩展不同节点，构建更大的知识网络

---

### 第四步：查看维基百科 📖
**右键单击**任意节点（如"香农熵"）

**预期结果**:
- ✅ 弹出节点详情面板
- ✅ 显示节点基本信息（学科、定义）
- ✅ 加载维基百科内容：
  - 标题
  - 描述
  - 详细摘要
  - 缩略图（如果有）
  - 跳转链接

**操作**:
- 点击"在维基百科中查看完整内容 →"跳转到维基百科
- 点击面板外部或"✕"按钮关闭面板

---

### 第五步：查看文献推荐 📚
在节点详情面板中向下滚动

**预期结果**:
- ✅ 显示"📚 相关文献推荐"部分
- ✅ 列出 5 篇相关学术论文
- ✅ 每篇论文包含：
  - 标题
  - 作者（最多3位）
  - 发表年份
  - 会议/期刊名称
  - 摘要（前300字）
  - 引用次数
  - 查看链接

**操作**:
- 悬停在论文卡片上，观察动画效果
- 点击"查看论文 →"跳转到 Semantic Scholar

---

### 第六步：导出图谱 📥
点击右上角的"📥 导出图谱"按钮

**测试三种格式**:

#### 1. 导出为 JSON
- 包含完整的节点和边数据
- 适合程序处理和数据分析

#### 2. 导出为 PNG
- 高清图谱截图
- 适合演示和报告

#### 3. 导出为 Markdown
- 详细的分析报告
- 包含统计信息、学科分类、关系详情
- 适合文档和学习笔记

---

## 🎯 完整演示脚本

### 场景：探索"神经网络"的跨学科关联

```
1. 输入概念："神经网络"
   → 生成图谱（涉及计算机科学、神经科学、数学等）

2. 查看智能摘要
   → 了解神经网络的跨学科特征

3. 左键点击"反向传播"节点
   → 扩展出梯度下降、链式法则等相关概念

4. 右键点击"梯度下降"节点
   → 查看维基百科：了解基本定义
   → 查看文献推荐：阅读经典论文

5. 右键点击"生物神经元"节点
   → 对比计算机科学和神经科学的不同视角

6. 导出为 Markdown
   → 生成完整的学习报告
```

## 🌟 演示亮点

### 1. 跨学科关联挖掘
- 自动发现不同学科间的"远亲"概念
- 例如："熵"连接物理学、信息论、统计学

### 2. 智能分析
- LLM 生成的自然语言摘要
- 提炼核心洞察和关键概念

### 3. 知识增强
- 维基百科提供权威定义
- 学术论文支持深入学习

### 4. 交互体验
- 左键扩展、右键查看
- 动态可视化、实时更新

### 5. 数据导出
- 多种格式满足不同需求
- 一键生成详细报告
