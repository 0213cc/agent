# 演示说明文档

## 1. 项目概述

**跨学科知识图谱智能体**是一个基于云原生架构的智能系统，旨在解决知识碎片化问题，帮助用户发现不同学科间的深层联系。

### 1.1 解决的痛点

- **知识碎片化严重**: 学习过程中难以建立跨学科的知识联系
- **概念孤立**: 不清楚一个概念在不同学科中的应用和关联
- **缺乏系统性**: 难以看透学科间的内在联系

### 1.2 核心价值

- 🔍 **智能挖掘**: 自动发现跨学科概念关联
- ✅ **严格校验**: 多重验证机制确保准确性
- 📊 **可视化**: 直观展示知识网络
- 🚀 **云原生**: 容器化部署，易于扩展

## 2. 演示准备

## 7. 常见问题准备

### Q1: 如何确保关系的准确性？

**回答**: 我们实现了三重校验机制：

1. 直接验证：使用专门的验证 Prompt 评估关系
2. 反向验证：从目标概念反向验证关系
3. 置信度过滤：只保留置信度>0.6 的关系

### Q2: 为什么选择 Neo4j？

**回答**: Neo4j 是原生图数据库，专门为图结构设计：

- 高效的图查询（Cypher 语言）
- 支持复杂的图算法
- 可视化工具完善

### Q3: 系统如何扩展？

**回答**:

- 无状态设计，支持水平扩展
- 提供 Kubernetes 配置文件
- 使用 Redis 缓存减少 LLM 调用
- 可以配置多个后端实例

### Q4: 支持哪些 LLM？

**回答**:

- 默认使用 OpenAI GPT-4
- 支持 Azure OpenAI
- 可以配置本地模型（如 Ollama）
- 只需修改环境变量即可切换
