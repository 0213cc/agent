### 智能体设计 ⭐⭐⭐⭐⭐

✅ **多阶段 Prompt 工程**
```
阶段1: 概念识别 (T=0.3) → 准确识别学科归属
阶段2: 跨学科挖掘 (T=0.7) → 发现5个学科的关联
阶段3: 关系验证 (T=0.3) → 直接验证合理性
阶段4: 反向验证 (T=0.3) → 双向确认一致性
```

✅ **三重校验层**
1. **直接验证**: 评估关系的真实性和准确性
2. **反向验证**: 从目标概念反向确认关系
3. **一致性检查**: 多次采样验证结果一致性

✅ **防幻觉机制**
- 低温度采样（验证阶段 T=0.3）
- 结构化输出（强制 JSON 格式）
- 置信度阈值过滤（>0.6）
- 明确约束条件（"只输出确定性强的关联"）

✅ **推理链路 (CoT)**
