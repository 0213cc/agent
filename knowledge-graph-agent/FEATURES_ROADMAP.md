### 🔄 功能 5: 用户评分系统
**优先级**: ⭐⭐⭐
**预计时间**: 60 分钟
**实现内容**:
- 用户可以对图谱评分（1-5 星）
- 存储多个版本的图谱
- 默认返回评分最高的版本
- 显示历史版本列表
- 用户可以选择查看其他版本

**技术方案**:
- 重构缓存结构：
  ```
  graph:{concept}:versions -> [
    {
      version_id: "v1",
      timestamp: "2026-01-19T12:00:00",
      rating: 4.5,
      vote_count: 10,
      graph_data: {...}
    }
  ]
  ```
- 后端：修改 `/api/graph/generate` 逻辑
- 后端：添加 `/api/graph/rate` 端点
- 前端：添加评分 UI 和版本选择器

**依赖**: 需要重构现有缓存机制
**⚠️ 注意**: 这是最复杂的功能，会影响现有缓存逻辑

## 🌐 云原生特征总结

### 已实现的云原生特征
1. **容器化部署** - Docker + Docker Compose
2. **微服务架构** - 前端、后端、数据库、缓存分离
3. **外部 API 集成** - 维基百科、Semantic Scholar
4. **异步处理** - aiohttp 非阻塞 HTTP 请求
5. **缓存机制** - Redis 缓存图谱数据
6. **图数据库** - Neo4j 存储知识图谱
7. **RESTful API** - 标准化接口设计
8. **容错处理** - 网络失败优雅降级

### 待实现的云原生特征
- **Kubernetes 部署** - K8s 配置文件（已准备）
- **服务发现** - 动态服务注册
- **负载均衡** - 多实例部署
- **监控告警** - Prometheus + Grafana
