## ✅ 功能 1: 图谱导出

### 测试步骤
1. 生成一个知识图谱（如"熵"）
2. 点击右上角的"📥 导出图谱"按钮
3. 测试三种导出格式：
   - **JSON**: 验证文件包含完整的节点和边数据
   - **PNG**: 验证图片清晰度和完整性
   - **Markdown**: 验证报告格式和内容完整性

### 预期结果
- ✅ 三种格式都能成功下载
- ✅ 文件名包含概念名称和时间戳
- ✅ Markdown 报告包含统计信息、学科分类、关系详情

## ✅ 功能 3: 维基百科集成

4. 验证维基百科信息：

   - 缩略图（如果有）
   - "在维基百科中查看完整内容"链接

### 预期结果
- ✅ 右键点击节点打开详情面板
- ✅ 维基百科信息加载成功
- ✅ 点击链接跳转到维基百科页面
- ✅ 对于生僻概念，显示"未找到相关维基百科条目"

### 测试用例
- **常见概念**: "熵"、"神经网络" → 应该有完整信息
- **生僻概念**: 随机生成的节点 → 可能无结果

## ✅ 功能 4: 文献推荐

### 测试步骤
1. 生成一个知识图谱
2. **右键点击**任意节点
3. 在节点详情面板中向下滚动到"📚 相关文献推荐"部分
4. 验证论文信息：
   - 论文标题
   - 作者列表（最多3位）
   - 发表年份
   - 会议/期刊名称
   - 摘要（前300字）
   - 引用次数
   - "查看论文"链接

### 预期结果
- ✅ 显示最多 5 篇相关论文
- ✅ 论文信息完整准确
- ✅ 点击"查看论文"跳转到 Semantic Scholar
- ✅ 卡片悬停时有动画效果（左移 + 阴影）
- ✅ 对于无结果的概念，显示"暂无相关文献"

### 测试用例
- **学术概念**: "神经网络"、"深度学习"、"量子计算" → 应该有大量论文
- **通用概念**: "熵"、"信息论" → 应该有跨学科论文
- **生僻概念**: 可能无结果

## 🐛 已知问题和注意事项

### 缓存问题
- **现象**: 连续两次生成同一概念，第二次仍然显示 Cache MISS
- **原因**: 正在调查中
- **影响**: 不影响功能使用，只是性能优化问题

### 交互说明
- **左键单击节点**: 扩展节点，生成新的关联
- **右键单击节点**: 查看节点详情（维基百科 + 文献推荐）
- **不要混淆**: 两种点击方式功能不同

### API 限制
- **Semantic Scholar**: 有速率限制，频繁请求可能被限流
- **维基百科**: 免费无限制，但网络不稳定时可能失败
