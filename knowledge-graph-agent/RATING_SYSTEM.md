# 用户评分系统说明文档

## 📊 功能概述

用户评分系统允许用户对生成的知识图谱进行 1-5 星评分，帮助评估图谱质量。

## ✨ 功能特点

### 1. 简单直观的评分界面
- **星级评分**：1-5 星，点击即可评分
- **悬停效果**：鼠标悬停时星星高亮
- **动画效果**：评分时有脉冲动画

### 2. 实时统计
- **平均评分**：显示当前图谱的平均评分
- **评分人数**：显示有多少人评过分
- **用户反馈**：提交后显示感谢信息

### 3. 持久化存储
- **Redis 存储**：评分数据存储在 Redis 中
- **按概念存储**：每个概念的图谱独立评分
- **累计统计**：自动计算平均分和总人数

## 🎯 使用方法

### 1. 生成图谱
- 输入一个概念（如"人工智能"）
- 点击"生成图谱"按钮
- 等待图谱生成完成

### 2. 查看评分
- 图谱下方会显示评分区域
- 如果已有评分，会显示平均分和评分人数
- 例如：**4.5 ⭐⭐⭐⭐⭐ (10 人评分)**

### 3. 提交评分
- 点击 1-5 颗星中的任意一颗
- 系统会自动提交评分
- 显示更新后的平均分
- 提示"感谢您的评分！您给了 X 星"

## 🔧 技术实现

### 后端 API

#### 1. 提交评分
```
POST /api/graph/rate
Body: {
  "concept": "人工智能",
  "rating": 5
}

Response: {
  "success": true,
  "data": {
    "avg_rating": 4.5,
    "vote_count": 10
  }
}
```

#### 2. 获取评分
```
GET /api/graph/rating/{concept}

Response: {
  "success": true,
  "data": {
    "avg_rating": 4.5,
    "vote_count": 10,
    "total_rating": 45
  }
}
```

### Redis 数据结构

```
Key: rating:{concept}
Value: {
  "total_rating": 45,    // 总评分（所有用户评分之和）
  "vote_count": 10,      // 评分人数
  "avg_rating": 4.5      // 平均评分
}
```

## 📝 使用建议

### 1. 评分标准（建议）
- **5 星**：图谱非常完整，关系准确，洞察深刻
- **4 星**：图谱质量良好，有少量可改进之处
- **3 星**：图谱基本可用，但有明显不足
- **2 星**：图谱质量较差，需要大幅改进
- **1 星**：图谱不可用或严重错误

### 2. 测试建议
- 生成多个不同概念的图谱
- 对每个图谱进行评分
- 刷新页面后评分应该保持
- 多次评分会累加到总评分中

### 3. 数据管理
- 评分数据存储在 Redis 中
- 不会自动过期（永久保存）
- 如需清除评分数据：
  ```bash
  docker exec kg-redis redis-cli KEYS "rating:*" | xargs docker exec kg-redis redis-cli DEL
  ```
